💡 COMMENT FONCTIONNE LE SYSTÈME ?

  • Format : CMD-MAXI-YYYYMMDD-NNN
  • CMD-MAXI : Code fixe de la boutique
  • YYYYMMDD : Date du jour (ex: 20260123)
  • NNN : Numéro séquentiel sur 3 chiffres (001, 002, 003...)
  • Le compteur s'incrémente automatiquement à chaque nouvelle commande
  • Le compteur se réinitialise chaque jour à minuit
  • Les données sont sauvegardées dans le localStorage du navigateur
