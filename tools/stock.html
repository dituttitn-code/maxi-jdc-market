ℹ️ Instructions

Comment utiliser :

  1. Recherchez un produit par code, nom ou catégorie
  2. Utilisez les interrupteurs pour changer l'état (EN STOCK / RUPTURE)
  3. Sélectionnez plusieurs produits avec les cases à cocher
  4. Utilisez les boutons d'actions en masse pour modifier plusieurs produits à la fois
  5. Cliquez sur "Sauvegarder TOUS les changements" pour mettre à jour le fichier stock.csv
  6. Les changements seront immédiatement visibles dans l'application principale

⚠️ Important : Les changements ne sont définitifs qu'après avoir cliqué sur "Sauvegarder"
